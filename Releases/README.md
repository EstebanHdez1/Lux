# Lux - Releases

Esta carpeta contiene los binarios compilados y listos para distribución de **Lux**.

## Contenido

- **`Lux.exe`**: Ejecutable principal autocontenido y optimizado (Release x64).
  - No requiere instalación ni runtimes externos (.NET, Electron, etc.).
  - Configuración automática mediante archivo `Lux.ini` local.
  - Compatible con Windows 10 (versión 2004+) y Windows 11.

## Uso

1. Ejecuta `Lux.exe`.
2. Verás el icono del sol (Tabler Sun) en la bandeja del sistema (System Tray).
3. Haz un clic izquierdo para abrir el control deslizante de brillo o clic derecho para acceder a las opciones de configuración y salida.
